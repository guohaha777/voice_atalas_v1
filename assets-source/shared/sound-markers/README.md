# 通用声音标记 · 透明源素材

四款标记具有相同的折纸卵石轮廓，区别仅用于辨认，不代表音源类别、音高、长短、轻响或情绪。任意录音都能使用；不依赖动物 / 植物素材库匹配。

| 文件 | 外观 |
| --- | --- |
| `marker-sage.png` | 浅鼠尾草绿，两道弧纹 |
| `marker-ochre.png` | 柔黄，三个圆点 |
| `marker-slate.png` | 灰蓝，两道斜纹 |
| `marker-lilac.png` | 浅紫，一道回环 |

- 每个文件 627 × 627，真实透明底。**没有烘焙编号或声音名称。**
- 编号和名称由实际界面数据叠加；同一音源在声卡、声场和曲谱中沿用同一标记。标记外观可以重复，不能只用颜色或四款外观当作唯一身份。
- 身份标记与五项声音参数分开：改变音高、轻响等选择，不更换身份标记；重复同一声音也沿用原标记。
- 成曲时持续时间尾条、选中描边、播放高亮等属于动态界面，不嵌进本 PNG。
- `masters/markers-atlas.png` 保留完整 2 × 2 透明母版。四个独立文件通过整格无损切片派生，不缩放、不重新绘画；切片矩形见资产清单。
- 用内置 imagegen 按已确认标记系统分离重建并移除固定数字；不是原参考的逐像素无损抠图。当前未接入页面，尚未生成网页压缩版本。
