# 首页 UI 修订 · 2026-10-23

以本轮用户确认覆盖历史首页记录：顶部入口缩小、标题字距和中轴修正、移除免登录提示和主按钮箭头、获奖说明位于画面内底部。

## 配色与导航

- 背景植物按「更透明 10 个百分点」处理：左上 opacity 22%、右上 36%、左侧 46%、右下 48%、左下 65%；角色和开场前景透明度不变。
- 用户最新指定青蛙采用植物偏灰绿的方向、植物采用青蛙偏黄绿的方向。`HomeToneFilters` 只对绿色超过红色和蓝色的像素应用局部调色；不重新生成图片，不改素材内容、透明度、位置、动效或图像尺寸。参数在首页 `config/scene.ts`。首页环境图及植物开场使用植物滤镜，青蛙单独使用灰绿滤镜，其他角色不调色。
- 增加「API 输入」入口。大屏四列等宽、高度 32px；700px 及以下两行两列、高度 30px。入口整组保持页面中轴，文字在窄屏不脱框。

## API 配置边界（用户已确认）

- 当前只实现配置弹窗，不调用模型。大语言模型与音乐模型分别填写服务地址、模型名称 / ID、API Key；允许仅配置一种。Key 按服务要求选填。
- 配置只在 App 的 React 内存中保留，关闭弹窗后重开可读取，刷新页面清空。不写 localStorage、sessionStorage、文件或服务端；不记录到日志。
- 提供隐藏 / 显示密钥、清空配置、应用到本次会话，以及独立缺项校验。应用成功仅表示前端会话记录完成，明确提示「尚未连接模型」。
- 后续真实接入另行确认服务端密钥处理与各供应商协议，当前配置不代表任意模型协议均可调用。

## 首页到声音诞生：交叉淡化（最新确认）

- 首页登录入口按用户指定写为「登陆」。万物声场删去「左边先响，右边后响 · 上下只是错开摆」，只移除可见文字，后续按用户纠正保留原布局占位（见声场验收文档）。
- 用户反馈树丛闭合存在白边、模糊与卡顿后，确认改用约 400ms 的短交叉淡化。移除独立树丛转场、额外滤镜和图片缩放；首页既有开场保持原样。
- 路由切换时保留原首页 DOM 在前景，目标页真实挂载后，仅将首页透明度从 1 降到 0；结束后卸载首页。转场不复制、截图、压缩或放大图片。保留点击时的滚动偏移，避免固定前景时跳位。
- 声音诞生从首页进入时关闭自身的入场位移；模式保持到该页面卸载，淡化结束不会重新播放入场动画。独立访问声音诞生继续使用原入场效果。
- 交互锁避免重复进入；浏览器返回或其他导航会取消淡化。系统减少动态效果、节省流量或 2G 提示下直接进入。若目标代码未就绪，最多保留首页 1500ms，再显露已有加载界面，避免无限遮挡。
- 模块独立放在 `apps/web/src/app/transitions/home-birth/`：config 管理时长、state 管理生命周期、hook 管理导航协调与清理、组件及 CSS 管理页面叠放和透明度。
- 验证：67 项测试通过；类型检查、75 个资源校验及正式构建通过。浏览器检查 1280 × 800、320 × 568 的淡化过程、滚动后进入和中途返回；另检查 390、700/701、900/901px 宽度，无横向溢出。淡化时首页宽度保持原值，结束后旧 DOM 移除，控制台未见错误。
