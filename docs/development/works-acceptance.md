# 作品书架

更新：2026-10-23。状态：前端已实现（本次打开期间的内存数据），**等待用户验收**。未提交、未推送。

依据：用户 2026-10-23 要求“只列出本次打开期间做过的作品（刷新后就没了）”；工作页配色、实心童趣图标、向导动物沿用其他工作页。书架不在四步流程里，是辅助入口。

## 页面结构

路由 `/works`，代码单独分包（在万物成曲时预取）。

1. **顶栏**：四步流程（书架不在流程内，不高亮任何一步）· 声音库（说明在万物声场里，可一键过去）· 作品书架（当前页，高亮）。
2. **标题行**：“作品书架”+ 副标题；右侧向导是首页的**小蜗牛**，气泡说书架上有几首，或空书架时怎么放进来。标题行是共用组件 `shared/ui/WorkIntro`。
3. **如实标签**：黄色“仅本次打开期间保留 · 刷新就没了”，旁边写“登录后保存到账号、分享给班级，暂未开放”。
4. **作品卡片网格**（新的在前）：
   - 用这首作品自己的摆放画的**小曲谱**（同样的声音标记、同样的行、时长尾条），不另存图片；
   - 作品名；正在做的那首标“正在做的这首”；
   - 几个声音 · 约几秒（实际长度）· 心情（心情脸 + 文字）；
   - 几点放进书架 · 仅自己可见；
   - “打开听听”：把这首设为当前作品，进入万物成曲继续听、改、再保存。
5. **空书架**：小蜗牛 + “还没有作品”+ 说明 +“去做一首”（进声音诞生）；有当前作品时还有“回到万物成曲”。

## 行为

- 作品来自万物成曲的“保存这首作品”。同一首再保存会**替换**书架里那一首（作品 ID = 摆放 ID），并移到最前。
- 打开另一首时，如果当前那首是孩子自己的、有声音、而且现在的样子还没放进书架，先问“先回去保存 / 换成这首”。
- 刷新后书架为空（内存数据），页面如实写明。
- 首页顶栏、各工作页顶栏的“作品书架”都进入本页；万物成曲保存后提示里也有“去作品书架看看”。

## 数据与接口

| 路径 | 职责 |
| --- | --- |
| `packages/contracts/src/work.ts`（`work-v1`） | `SavedWork`（ID、名字 ≤ 16 字、摆放快照、成曲设置、可见范围、保存时间）与 `parseSavedWork` 校验 |
| `shared/creation/workShelf.ts` | 本次打开期间的书架（内存）：`list` 新的在前、`put` 校验后放入 / 替换、`subscribe` |
| `shared/creation/workSession.ts` | 当前作品；`open(work)` 把书架里的作品设为当前作品 |
| `pages/works/services/shelfRepository.ts` | **后端端口**：`list`、`subscribe`、`currentId`、`hasUnsavedCurrent`、`open`；预留 `GET /api/v1/works?owner=me`、`GET /api/v1/works/{workId}`（服务端按账号和可见范围过滤） |
| `pages/works/model/useWorkShelf.ts` | 用 `useSyncExternalStore` 订阅书架和当前作品 |
| `pages/works/components/WorkCard.tsx` | 卡片；小曲谱用 `shared/creation/arrangementTiming` 的 `timedEvents` / `pieceSeconds`，与万物成曲同源 |
| `pages/works/config/copy.ts` | 文案与蜗牛向导；心情文字来自 `shared/creation/moodCopy` |
