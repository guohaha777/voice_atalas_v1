新文本按语义使用共享字号变量，避免另起一套固定字号或在全局追加页面选择器。字号使用 `rem + clamp`，正文、标题、按钮分别设置无单位行高；容器约束和断点仍归组件所有。

默认 16px 根字号下，辅助信息约 11–13px、正文约 14–15px、按钮约 14–17px、页标题约 22–32px。手绘首页标题仍为原始图像及 sprite，标记上的字继续按角色尺寸 / 容器比例计算。

## 本轮处理

- 声场工具栏允许按可用宽度换行，较窄的操作区分成两行，避免主按钮文字挤成末尾单字。提示不再被其他控件挤成一字竖排。701px 宽下，提示从约 14 × 216px 恢复为约 347 × 22px。
- 工作页标题与向导在平板宽度纵向排列；导航保留当前步骤，长文本支持自然换行。
- 成曲播放区按曲谱卡片的实际宽度使用 container query，依次安排播放、重播、时间与进度；较窄桌面侧栏也适用。
- 声场和曲谱按标记尺寸与行数预留最小行高，文字 / 名称与角色不会依赖过小的行空间。心情选项按容器宽度切换为 3 × 3，避免「先不选」「自己写」被截断。
- 首页手绘标题改为连续、有上限的尺寸规则，消除 700/701px 前后的尺寸突变；保留原素材与纵向中轴。
- 声音诞生的长名称正常换行，「试听」保持完整，不被压成竖排。
- 作品卡片标题、状态标签和元信息支持换行，列表列宽不超出容器。
- 窄课本灵感弹窗给名称与说明完整行宽；很窄的共用弹窗将两个操作按钮上下排列，保持文字完整。
- 图片继续使用既有素材与原比例；本轮不重新生成、重裁或压缩素材，不改音频、编排、数据契约和服务行为。

## 同日修正：一页只用一个声音说话

- 规则：页标题副标题说“这一页是做什么的”；角色（声音诞生的声音标记、声场的青蛙、成曲的松鼠）说“下一步做什么”和所有提示（错误用粉色气泡）；控件旁只留“这个控件怎么用”。同一句话不再在两处出现。
- 声音诞生：页签里的提示条、五行下方的提示行、声卡里“先在上方录音…”都去掉；这些提示由声音标记在气泡里说（约 8 秒后回到平时的话），“还没选声音”时它本来就在说「先给我一个声音吧！」，所以只蹦一下，页签里「还没有选声音」那行加上粉色荧光笔底并轻轻晃一下（每次点都会重放，选好声音后消失）。声卡空状态改为一条安静的虚线波形。声卡信息表单自己的提示仍留在表单里。
- 万物声场：提示由青蛙说；去掉声场里的「点左边的声音，再点这里放下」；副标题改为「越往右越晚响起；尾巴有多长，声音就响多久。」，青蛙相应几句不再重复这两点。
- 万物成曲：提示由松鼠说；保存后松鼠说「放进作品书架啦！只在这次打开期间保留，刷新就没了。」，曲谱上方那一格暂时换成「去作品书架看看」按钮；空曲谱只留「回声场摆一摆」按钮；副标题与进度条下的说明不再重复“竖线走到哪里就亮起来”。
- 只改显示位置和文案，逻辑、状态与路径不变。`npm test` 67 项、`npm run build` 通过；浏览器核对：声音诞生无声音点“做好了”、上传非音频文件，声场清空后点“摆好了”，成曲示例点保存与真实保存后的去书架按钮，1440 × 900 下均为一屏、位置不跳。

## 同日整理：短屏断点统一、拆分大文件、弱网加载

- **断点统一**：所有屏幕档位只在 `apps/web/src/styles/breakpoints.ts` 定义一次（11 档）。CSS 写 `@media(--short)`，构建时由 `vite.config.ts` 的 `wanwu-custom-media` 小插件展开；JS 用 `media.phone`、`media['reduced-motion']`。`scripts/check-styles.mjs` 加入 `npm run build`：写死像素的媒体查询、未知档位、超过 220 行的源文件都会让构建失败。
  - 两处取整：`max-width:359px` 与 `360px` 合并为 `--tiny`（≤ 360px），`max-height:720px` 与 `740px` 合并为 `--shorter`（≤ 740px）。只在恰好 360px 宽、或 721–740px 高时有差别：360px 宽时万物成曲底部两个按钮的图标间距由 10px 变为 6px；万物声场与成曲在 721–740px 高时也会收起副标题、标记略小（与声音诞生一致）。其余尺寸完全不变。
- **拆分大文件**（功能、视觉、逻辑不变）：
