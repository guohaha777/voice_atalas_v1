# 声音入口 · 开始方式弹窗（原 A 版）

日期：2026-10-22。状态：前端已实现，等待用户验收画面。视觉基准：`万物声谱_视觉过程稿/定稿页面参考/2026-10-22-四步流程/01-home-start-dialog.png`。

## 范围

首页“开始成曲”打开三选一弹窗：制作声卡、上传声音、从声音库挑选。白面板 + 三组纸艺入口插画 + 稀疏角落草木（左上复用首页枝叶，左下池塘，右下蕨草），背后是轻遮罩下的首页。桌面 / 平板三列，手机每项一行（插画在左、选项在右）。

- 无默认选项；选中后按钮文字变为“继续制作声卡 / 继续上传声音 / 继续挑选声音”。
- 三个下游入口都还没有页面：点击继续后按钮变“暂未开放”，下方如实提示，切换入口即清除。不请求相机 / 麦克风，不选文件，不接登录、存储、模型或后端。
- 精简：去掉与右上角关闭重复的“回到森林”文字按钮；去掉常驻的引导提示行，只在需要时显示状态。关闭仍支持 ×、Esc、点遮罩。
- 标题“这一次，想从哪里开始？”用手绘图，h2 始终保留真实文字作为可访问名称。

## 资源与弱网

- 配方 `docs/assets/start-recipe.json`，脚本 `scripts/build-art-assets.mjs`（已并入 `npm run assets:build`）。按透明边界裁紧，三组插画同一缩放保留相对大小，输出手机 / 桌面 WebP 与调色板 PNG 回退，内容哈希命名；公开清单 `docs/assets/start-release-manifest.json`，运行清单 `pages/start/config/start-assets.generated.json`。原 PNG 不进 public。
- 体积：手机 ≈ 99 KB、桌面 ≈ 262 KB、PNG 回退 ≈ 130 KB（6 张）；预算 180 / 330 / 360 KiB，由 `check:assets` 与测试校验。左上枝叶直接复用首页已加载的衍生图，零额外请求。
- 首页加载完成 3 秒后、主线程空闲时低优先级预取当前尺寸档的弹窗图；Save-Data / 2G 不预取，只在打开时加载。
- 打开弹窗时文字和单选立即可用，插画区域按比例预留、加载后淡入，不跳版。标题图 1.6 秒内未解码则保持文字标题，不再迟到替换。插画两级都失败时改为细线图标，选项仍可用。

## 已检查

- `npm test`：15 项通过（新增 5 项：入口状态 4 项、弹窗资源清单 / 预算 1 项）。
- `npm run build`：TypeScript、69 项公开资源校验（含弹窗 18 个衍生文件与预算）、Vite 构建通过。
- 内嵌浏览器（`npm run preview` 构建产物）：1440 × 900、1280 × 720、768 × 1024、390 × 844、320 × 568。前四个尺寸无需滚动；320 × 568 弹窗内部滚动，继续按钮首屏可见；均无横向溢出。按元素坐标核对，装饰不压选项文字和按钮。
- 点击插画即可选中；继续 → 暂未开放 → 切换清除；方向键切换单选；焦点框可见；Esc / × 关闭后焦点回到“开始成曲”，滚动锁解除；重开时重置为未选择。
- 首页鸟鸣播放中打开弹窗：声音停止，关闭后不自动续播。
- 模拟插画 URL 失败：退回细线图标，选项仍可选。标题图超时时显示文字标题（内嵌浏览器面板处于后台时实际出现过）。
- 控制台无错误。
