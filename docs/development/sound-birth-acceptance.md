## 页面结构

路由 `/create`，首页“开始成曲”直接进入（2026-10-23 删除开始方式弹窗和 `?from=` 参数，页面不再按入口预先打开声音库或高亮某个采集入口）。电脑上整页一屏放下（1440 × 900、1366 × 768、1280 × 720 已核对，网格行高固定，角色按剩余高度缩放），手机上下排列、底部按钮吸底。

1. **顶栏**：品牌 · 四步流程（带序号）· 声音库 · 作品书架（未开放，如实提示）。共用组件，本次未改。
2. **左列 · 我的声卡**：微斜的纸卡，顶上一条粉色胶带，草绿边、奶油渐变。名字（可改名）、来源行（本机为“记录人 · 地点 · 日期”或“本机文件 · 未上传”，示例为“示例声音 · 提供 · 来源与许可”）、「修改信息」（已确认的本机声音）。波形用真实峰值画成波线，有了“现在的”版本后原声以虚线垫在后面（带图例），已播放部分加深，左侧播放键、右下计时保留；下面是听现在的 / 听原声。没有声音时显示入口对应的提示。
3. **左列 · 声音标记角色**（`shared/markers/SoundSpirit`）：声卡下面站着当前声音的标记（`markerIndex` 决定四款中的哪款），纸艺身体不变，眼睛和手臂由代码画。
   - 没有声音时半睡半醒、手垂下；有声音后醒来挥手。眼睛跟随鼠标，偶尔眨眼；点它会挥手并说“你好呀！”。
   - 右手（仅桌面宽度）指向“正在看的那一行”，不碰到行；左手悬在身边地面上方，跟着正在播放的声音（真实峰值、共用音频时钟）每次起音拍一下地，荡开一圈（拍地行程约 120 个标记单位，参数在 `spiritPoses.ts` 的 `spiritArm`）。身体随响度轻轻鼓动；每选一项跳一下，五项选满时欢呼并冒小星星。
   - 气泡：选完一项先显示声音联想提示（`SoundHintProvider`，原小鸟向导的内容），6 秒后回到“我现在高高的、……”；播放时“听，我在唱歌～”；没声音时“先给我一个声音吧！”。
   - 做声音的人写在标记右下角，点击可修改（最多 6 个字）；分组标签在舞台右下角。
   - 本机声音的**编辑状态**：声卡信息表占据舞台，角色缩小站在右上方、气泡在左，右手不指行；「确认声卡信息」后角色回到大尺寸。
4. **右列 · 标题**：标题与副标题。原标题行右侧的小鸟向导已去掉，提示并入角色气泡。
5. **右列 · 当前声音页签（采集）**：白色页签压在“声音的样子”上沿。标记 + 编号 + 名字（示例标签）+ 试听；录音 · 上传声音 · 从声音库挑选 · 拍照读声卡四个实心纸片图标（粉 / 天蓝 / 黄 / 灰绿，无底衬）；入口提示与读取 / 错误提示保留。
6. **右列 · 声音的样子（转译）**：五行同时平铺，每行有纸片图标（草绿 / 黄 / 天蓝 / 粉 / 浅紫）。一次突出一行（悬停、聚焦，或选完一项 1.5 秒后自动移到下一个未选项）：该行抬起、左侧出现草绿竖条、显示一句提问（如“声音能响多久？”）。选项是凹槽里的白色小垫子，选中为实心立体草绿并打勾，播放中显示音量条；已选的行名后有小圆点。右上角五个小圆点 + “已选 N / 5”。**五项都可以不选**（2026-10-23）：不选的一项保持原声（原音高、原长度、原音量、只出现一次），再点一下已选的选项就取消，取消后立即播放新的效果；副标题写明“选一项听听变化，再点一下就取消；不选的保持原声”。底部返回入口 · 做好了，去万物声场（声音和来源信息齐了就变实心并轻轻呼吸）。
7. **背景**：页面草稿的柔和渐变底；本页不再显示首页灌木环境层（其他工作页不变）。

## 声卡信息与溯源

| 字段 | 说明 |
| --- | --- |
| 来源名称 | 默认文件名或“我的录音”，与孩子起的声卡名字分开保存 |
| 分组 | 例如“秋天的后山”；用过的分组以标签形式放在“分组”标题行，可一键复用；声音库按分组归类 |
| 记录人（昵称） | 可从已用过的昵称里选；只写昵称 |
| 日期 | 默认今天 |
| 大致地点 | 可从已用过的地点里选；只写大致范围 |
| 可见范围 | 只读：仅这台设备 · 共享未开放 |

- 新的本机声音沿用上一次的记录人、地点、分组。确认前必须填齐来源名称、记录人、日期、地点。
- 点“做好了”时按顺序引导：先选声音 → 缺来源信息时滚到并聚焦第一个空格。五项不再是必选（2026-10-23 起），一项不选也能进入万物声场。信息已齐但没点确认的会自动确认。全部完成后，万物声场显示暂未开放，页面上的内容都保留。
- 本机声音和档案只在本次打开期间保留（内存），声卡信息标题右侧写明。

## 真实前端状态（不接后端 / AI）

- **示例声音**：首页 5 段已授权声音，按需加载，12 秒超时可重试，带来源许可链接。班级和公共声音库如实写明未开放。
- **录音**：录音对话框的流程是开始 → 计时（最长 45 秒）→ 停止 → 听一听 → 重录 / 用这段。录音时关闭回声消除和降噪，结束后释放麦克风；权限、非 https、太短等情况都有提示。
- **上传**：在本机解码，限制 20MB，标为“本机文件 · 未上传”。超过 45 秒的文件（2026-10-23 起）打开“这段声音有点长”弹窗：默认选前 45 秒，可以拖两端、拖整段、点波形把整段移过去，或用方向键 / Shift / Home / End / PageUp / PageDown 调整；一段在 1～45 秒之间，可试听，「用这段声音」后只把这一段作为声源（设备上的原文件不动），「不用了」放弃。超过 10 分钟的文件直接提示太长（避免手机解码占用过多内存）。
- **纸卡**：照片只留在本机，可放大、重拍、移除。读卡识别未开放，页面如实提示需要对照照片手动选择。
- **效果试听**：在浏览器里离线渲染，原声只读。规则在 `shared/audio/shapingRules.ts`：高低 ±3 半音，轻响 −10 / −5 / −1 dB，长短、变化、出现方式各有对应规则，总长不超过 10 秒。
- **向导提示**：`services/soundHints.ts` 的 `SoundHintProvider` 接口。现在用 `config/hintPresets.ts` 的 16 条手写提示（来源标为 `preset`，不是 AI 生成）。接入模型和提示词时实现同一接口，本地文案保留作离线兜底。
