# 声音诞生（合并采集与转译）

更新：2026-10-23。状态：**已验收**（2026-10-22）。之后只有音源上限改为 45 秒和共用模块整理，画面与操作不变。本文件先写**当前状态**，最后附简短的版本记录；以当前状态为准。

依据：定稿结构 `万物声谱_视觉过程稿/定稿页面参考/2026-10-22-四步流程/02-sound-birth.png`；采集与转译的命名 / 分组溯源参考原 demo（https://naturesoundatlas.netlify.app/ 及源码 `atalas/src/page-shells/CardGalleryPage`，只读参考）；配色依据用户给的春季配色图。

## 页面结构

路由 `/create?from=card|upload|library`，弹窗三个入口进入同一页的不同初始状态（`library` 直接打开声音库；`card`、`upload` 高亮对应采集入口）。电脑上整页一屏放下（1440 × 900、1366 × 768、1280 × 720 已核对），手机上下排列、底部按钮吸底。

1. **顶栏**：品牌 · 四步流程（带序号）· 声音库 · 作品书架（未开放，如实提示）。
2. **标题行**：标题和副标题在左；右侧是本单元的向导小鸟（首页同一张图，镜像后面朝气泡）和对话气泡。每选一个特征，气泡显示一句声音联想提示，小鸟轻跳一下。
3. **当前声音条（采集）**：标记 + 编号 + 名字 + 试听；录音 · 上传声音 · 从声音库挑选 · 拍照读声卡，四个圆形童趣图标。
4. **我的声卡**：
   - 本机声音先是**编辑状态**：紧凑声卡（舞台、名字、波形、听原声 / 听现在的）+ 声卡信息表 + 「确认声卡信息」。
   - 确认后，或示例声音，显示**大声卡**：舞台上有对话气泡（描述当前选择）、标记、做声音的人（写在标记上，可点击修改，最多 6 个字）、左下角分组标签；名字下是“记录人 · 地点 · 日期”（示例为“示例声音 · 提供 · 来源与许可”）；波形与对比按钮；「修改信息」可回到编辑。
5. **声音的样子（转译）**：五行同时平铺——高低、长短、变化、轻响、出现方式，每项 3～4 个选项。点一下就选中并播放效果，选中为实心色块；右上角渐变进度条“已选 N / 5”。底部是返回入口 · 做好了，去万物声场。
6. **背景**：首页场景的五块环境层，按首页的摆放方式铺在窗口四周，不透明度 12%；手机上不显示。

## 声卡信息与溯源

| 字段 | 说明 |
| --- | --- |
| 来源名称 | 默认文件名或“我的录音”，与孩子起的声卡名字分开保存 |
| 分组 | 例如“秋天的后山”；用过的分组以标签形式放在“分组”标题行，可一键复用；声音库按分组归类 |
| 记录人（昵称） | 可从已用过的昵称里选；只写昵称 |
| 日期 | 默认今天 |
| 大致地点 | 可从已用过的地点里选；只写大致范围 |
| 可见范围 | 只读：仅这台设备 · 共享未开放 |

- 新的本机声音沿用上一次的记录人、地点、分组。确认前必须填齐来源名称、记录人、日期、地点。
- 点“做好了”时按顺序引导：先选声音 → 把没选的项标出并滚到第一行 → 缺来源信息时滚到并聚焦第一个空格。信息已齐但没点确认的会自动确认。全部完成后，万物声场显示暂未开放，页面上的内容都保留。
- 本机声音和档案只在本次打开期间保留（内存），声卡信息标题右侧写明。

## 真实前端状态（不接后端 / AI）

- **示例声音**：首页 5 段已授权声音，按需加载，12 秒超时可重试，带来源许可链接。班级和公共声音库如实写明未开放。
- **录音**：录音对话框的流程是开始 → 计时（最长 45 秒）→ 停止 → 听一听 → 重录 / 用这段。录音时关闭回声消除和降噪，结束后释放麦克风；权限、非 https、太短等情况都有提示。
- **上传**：在本机解码，限制 20MB、45 秒（2026-10-22 起，原为 15MB、30 秒），标为“本机文件 · 未上传”。
- **纸卡**：照片只留在本机，可放大、重拍、移除。读卡识别未开放，页面如实提示需要对照照片手动选择。
- **效果试听**：在浏览器里离线渲染，原声只读。规则在 `shared/audio/shapingRules.ts`：高低 ±3 半音，轻响 −10 / −5 / −1 dB，长短、变化、出现方式各有对应规则，总长不超过 10 秒。
- **向导提示**：`services/soundHints.ts` 的 `SoundHintProvider` 接口。现在用 `config/hintPresets.ts` 的 16 条手写提示（来源标为 `preset`，不是 AI 生成）。接入模型和提示词时实现同一接口，本地文案保留作离线兜底。

## 弱网与资源

- 本页代码单独分包，约 19 KB gzip，开始弹窗打开时预取，到达前显示带流程条的“正在打开…”。
- 标记、示例声音、向导和背景都复用已有的哈希文件（首页的大多已缓存）；示例声音只在试听或选用时下载；背景以低优先级加载，手机不加载。
- 示意图、波形、图标都是 SVG，不额外请求图片。
