规则：一次只推进当前页，用户确认正式前端后，再开始下一页。所有页面前端确认后，再接业务功能。

| 页面 | 本轮状态 |
| --- | --- |
| 首页 | 视觉和资产方向已确认；正式模块化迁移完成，等待本轮运行页确认 |
| 开始方式选择弹窗（第二步） | 已完成前端，等待画面确认；制作声卡 / 上传声音 / 从声音库挑选 |
| 三个入口对应的后续页面 | 未开始；当前继续操作明确显示暂未开放，不跳转到假页面 |

访客应能免登录使用示例声卡体验；现场录音和纸卡是课堂路径，不把登录和上传强加给访客。前端页面的呈现顺序、表单字段、错误和空态在对应页验收时决定。这里记录流程，不提前创建下一页。

2026-10-22 用户明确：首页“开始成曲”先弹窗选择制作声卡、上传声音或从声音库挑选；流程参照原项目，UI 延续当前正式首页。原 demo 的日记拍照与录音两组入口不直接搬到新版，按最新三入口约定呈现。此轮只完成选择弹窗，下一页不自动展开。
