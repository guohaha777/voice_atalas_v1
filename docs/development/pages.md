# 逐页开发与确认

规则：一次只推进当前页，用户确认正式前端后，再开始下一页。所有页面前端确认后，再接业务功能。

| 页面 | 本轮状态 |
| --- | --- |
| 首页 | 视觉和资产方向已确认；正式模块化迁移完成，等待本轮运行页确认 |
| 选择声音 / 示例声卡入口 | 未开始；建议作为下一页，顺序由用户确认 |
| 采集、录音、上传、活动 | 未开始 |
| 纸卡读取与确认 | 未开始 |
| 声音诞生 / 五个维度 | 未开始 |
| 万物声场 | 未开始 |
| 课本滤镜（可选） | 未开始 |
| 万物成曲、保存 | 未开始 |
| 声音库、作品书架 | 未开始 |
| 登录与老师 / 贡献者入口 | 未开始 |

访客应能免登录使用示例声卡体验；现场录音和纸卡是课堂路径，不把登录和上传强加给访客。前端页面的呈现顺序、表单字段、错误和空态在对应页验收时决定。这里记录流程，不提前创建下一页。
